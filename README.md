# Moodis Israel — PARK / LAB

Интерактивный учебный 3D-макет парковки сотрудников.

- Обзор на 360° и режим от первого лица из кабины водителя.
- Разборка устройств, прозрачные корпуса, подписанные узлы и кабели.
- Симуляция въезда, парковки и выезда по карте или теудат-зеут.
- Восемь парковочных мест с управляемыми NPC-машинами.
- Локальный реестр разрешённых и запрещённых номеров.
- Демонстрационный код Arduino.

## Запуск

Откройте `index.html` в современном браузере. Зависимости встроены в HTML; установка не нужна.

## GitHub Pages

В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.

После публикации демо: https://vadimgolovin3124.github.io/Moodis-Israel/

Реестр каждого посетителя хранится только в его браузере (localStorage). Используйте вымышленные тестовые номера. Размеры, внутреннее устройство и соединения демонстрационные; точное оборудование ещё не выбрано.
